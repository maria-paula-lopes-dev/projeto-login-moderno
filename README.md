# ✦ Projeto Login Moderno

Projeto de estudo desenvolvido com **HTML5 e CSS3**, focado na criação de um **layout moderno e totalmente responsivo**, adaptado para diferentes tamanhos de tela por meio de **media queries**.

## 🔗 Demonstração

⌁ Acesse o projeto online:  
[https://mariapaulalopes.github.io/projeto-login-modern/](https://maria-paula-lopes-dev.github.io/projeto-login-moderno/)

## ✧ Sobre o projeto

O **Projeto Login Moderno** tem como objetivo o desenvolvimento de uma **interface de login com design atualizado**, simulando uma aplicação real adaptável para **dispositivos mobile, tablet e desktop**.

Este projeto propõe uma **repaginação visual** em relação a um projeto anterior, explorando novas cores, tipografia e organização de layout, sem perder usabilidade e hierarquia visual.

## ✧ Objetivos

▸ Criar uma interface moderna e responsiva  

▸ Aplicar o conceito **Mobile First**  

▸ Melhorar a organização e manutenção do CSS  

▸ Explorar boas práticas de layout e design visual  

## ✧ Conceitos aplicados

▸ Abordagem **Mobile First**  

▸ Layout responsivo com **Flexbox**  

▸ Uso de **media queries** para diferentes breakpoints  

▸ Controle de proporção, cores e tipografia  

▸ Separação de estilos base e responsivos em arquivos distintos  

## ✧ Tecnologias utilizadas

▸ HTML5  

▸ CSS3  

▸ Flexbox  

▸ Media Queries  

## ✧ Aprendizados

Durante o desenvolvimento deste projeto, foram aprofundados os seguintes conhecimentos:

▸ Criação de layouts responsivos modernos  

▸ Aplicação de design visual sem comprometer a usabilidade  

▸ Definição estratégica de breakpoints  

▸ Organização de estilos CSS para melhor manutenção  

▸ Desenvolvimento de interfaces focadas na experiência do usuário
